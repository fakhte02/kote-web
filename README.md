# Kote Web

A full-stack e-commerce web application for an online jewelry store.

## About the Project

Kote Web is a personal software engineering project developed to build a complete
e-commerce platform for selling jewelry and accessories online.

The project focuses on backend development, database design, RESTful API development,
authentication, and deployment.

## Features

### Customer
- User registration and login
- Browse products
- View product details
- Add products to cart
- Update cart items
- Place orders
- View order history

### Admin
- Admin authentication
- Add, edit, and delete products
- Manage product inventory
- Manage orders

## Tech Stack

### Frontend
